네트워크란?

컴퓨터끼리 택배를 주고받는 약속된 시스템

3

네트워크는 거대한 택배망입니다

생활 속에서

택배를 보낼 때

  • 상자에 보내는 사람·받는 사람 주소를 적는다
  • 택배 회사가 여러 물류센터를 거쳐 배달한다
  • 송장 양식이 정해져 있어 누구나 같은 방식으로 보낸다
≈
네트워크에서

데이터를 보낼 때

  • 데이터 조각(패킷)에 출발지·목적지 IP를 적는다
  • 라우터들이 여러 구간을 거쳐 전달한다
  • 프로토콜(TCP/IP)이라는 공통 규칙을 따른다
네트워크 = 주소가 적힌 작은 상자(패킷)를 규칙대로 나르는 길

공인 IP와 사설 IP

회사 대표번호와 내선번호를 떠올리세요

회사 대표번호

공인 IP

전 세계에서 유일한 주소. 통신사가 우리 집 공유기에 1개 줍니다. 밖에서 찾아올 때 쓰는 번호.

내선번호

사설 IP

집 안에서만 통하는 주소. 192.168.x.x, 10.x.x.x, 172.16~31.x.x. 옆집에도 똑같은 번호가 있어도 됩니다.

실습

직접 확인

사설 IP: 리눅스에서 ip addr
공인 IP: curl ifconfig.me
두 값이 다르면 공유기 뒤에 있는 것!

공인 IP 하나를 온 가족이 나눠 쓰게 해 주는 장치

17

공유기가 하는 네 가지 일

작은 상자 하나가 아파트 관리실 역할을 모두 맡습니다

라우터

동네 우체국

집 안과 인터넷 사이에서 패킷의 길을 정합니다.

DHCP

호텔 프런트

기기가 들어오면 빈 방(사설 IP)을 자동으로 배정합니다.

NAT

전화 교환원

내선(사설 IP)을 대표번호(공인 IP)로 바꿔 밖에 연결합니다.

방화벽·Wi-Fi

경비실

밖에서 함부로 들어오는 연결을 막고 무선 신호를 뿌립니다.

NAT와 포트포워딩

주소가 바뀌는 문제와 해결책

서버의 주소는 안 바뀌게, 집의 공인 IP는 바뀌어도 따라가게

지정석

DHCP 고정 할당

서버의 MAC 주소에 192.168.0.10을 고정. 포트포워딩 대상이 바뀌지 않습니다.

가끔 이사

유동 공인 IP

가정용 회선은 공인 IP가 재부팅·계약 변경 시 바뀔 수 있습니다.

자동 주소록 갱신

DDNS

포트포워딩 vs VPN

처음엔 포트포워딩으로 원리를 배우고, 운영은 VPN 방식을 권장합니다

비교포트포워딩VPN (WireGuard · Tailscale)
비유건물 정문 옆 쪽문을 열어 둠출입증 있는 사람만 쓰는 비밀 통로

import json, os, urllib.request as u
T=os.environ['CF_TOKEN']; Z=os.environ['CF_ZONE']
R=os.environ['CF_RECORD']
ip=u.urlopen('https://api.ipify.org').read().decode()
api='https://api.cloudflare.com/client/v4'
url=f'{api}/zones/{Z}/dns_records/{R}'
body=json.dumps({'type':'A','name':'server',
  'content':ip,'ttl':300,'proxied':False}).encode()
req=u.Request(url,data=body,method='PUT',headers={
  'Authorization':f'Bearer {T}',
  'Content-Type':'application/json'})
print(json.load(u.urlopen(req))['success'], ip)
토큰은 코드에 적지 말고 환경변수로 — 깃에 올라가면 누구나 내 DNS를 바꿀 수 있습니다
