## 3. 과제 · "확인 필요" 표시 추가

요청: 담당자나 기한이 정해지지 않은 할 일은 **확인 필요**로 표시하고, 그런 할 일이 몇 건인지 결과에 넣는다.

| 번호 | 질문 | 내 답 (위치와 이유 한 줄) |
| --- | --- | --- |
| 1 | LLM이 할 일인가, 규칙이 할 일인가? |  |
| 2 | 할 일 하나마다 표시하는 곳과 더할 필드 |  |
| 3 | 몇 건인지 세는 곳과 더할 필드 |  |
| 4 | `No actions` 길의 결과에 넣을 것 |  |
| 5 | 항목 수가 바뀌는 곳이 생기나? |  |

바뀐 결과 형식 (예시 JSON):

```json
{"route": "할 일 정리", "count": 4, "summary": "", "actions": []}
```
