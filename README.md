# AI 워크플로우 수업 자료

노코드 멀티 에이전트 워크플로우 설계·운영 수업의 강의와 실습 자료입니다. 아래 표에서 오늘의 목표를 확인한 뒤, 해당 일차의 실습 README부터 열면 준비·실습 순서·과제·검증 명령을 볼 수 있습니다.

## 빠른 시작

1. 오늘 날짜에 맞는 **일차**를 아래 표에서 찾습니다.
2. **실습** 링크를 열어 준비 단계와 하루 진행 순서를 확인합니다.
3. `LAB-01` → `LAB-02` → `LAB-03` 순서로 진행합니다.
4. 작업 결과와 작성한 요청문은 각 일차의 `my-work/` 폴더에 저장합니다.

수업 운영 계획 전체는 [일별 커리큘럼 CSV](Doc/AIO-CURRICULUM-DAILY.csv)에 있습니다.

## 실습 문서 읽는 순서

각 일차 폴더에는 보통 아래 자료가 있습니다.

- `LECTURE-*.md` 또는 `README.md`: 하루의 전체 흐름과 준비 사항
- `LAB-01` ~ `LAB-03`: 단계별 실습과 과제
- `VIBE-REQ-*`, `VIBE-Q-*`: CLI 코딩 에이전트로 구현할 때 쓰는 요청서와 진행 가이드
- `reference/`, `answers/`: 비교용 예제와 수업 후 확인할 결과물
- `cases/`, `requests/`: 자동 테스트에 쓰는 입력 사례
- `my-work/`: 본인이 작성하는 프롬프트·설계·테스트 결과

각 실습 폴더의 README가 해당 일차의 기준 문서입니다. 명령과 API 키, Docker·n8n 실행 여부는 그 문서의 준비 절부터 확인하세요.
