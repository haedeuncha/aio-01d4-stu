## 7 / 30 · 1단계 · 왜 버전 관리인가

| 질문 | 필요한 것 |
| --- | --- |
| 어제와 오늘 사이에 **무엇이** 바뀌었나 | 변경 기록 · diff |
| 이 답은 **어느 버전이** 냈나 | 답 · 로그의 버전 (추적성) |
| 어제로 **돌아갈 수** 있나 | 지워지지 않은 이전 버전 (되돌리기) |
| 같은 입력이면 같은 결과인가 | 재현성 |

- 일반 소프트웨어: 코드가 같으면 결과가 같다. **LLM 앱: 코드가 같아도 모델 · 지시문이 바뀌면 다르다.** → MLOps · LLMOps.
